# Roadmap

## Shipped foundation

- Mobile-first OLED design system and installable offline shell
- Interactive 3D Earth with semantic point limits and event pulses
- Normalized Signal schema, validation, provenance, and freshness
- Live USGS vertical slice and deterministic multi-source Demo Mode
- H3 indexing, temporal windows, conservative relationships, Discoveries
- IndexedDB retention, saved Cases, search, Observer permission flow
- Unit tests and GitHub Actions verification

## Next

1. Add NWS alert polygons and NOAA SWPC global signals.
2. Move high-volume normalization/candidate generation into Web Workers.
3. Add lazy MapLibre investigation mode and polygon/track rendering.
4. Build transparent per-H3 temporal baselines and component-level scores.
5. Add Open-Meteo context and ambient Observer data.
6. Add credential-optional FIRMS, then conservative GDELT ingestion.
7. Add rate-aware OpenSky and SatNOGS layers with short retention.
8. Add replay snapshots, scrubber evolution, and provider-specific thinning.
9. Add focused entity graph with bounded progressive expansion.
10. Complete accessibility, battery, storage-management, and mobile performance audits.
